# AI-Assisted Web Development Portfolio

## Обо мне

Более 3 лет опыта удалённой работы, около 2 лет работы с CRM и онлайн-платформами. Использую ChatGPT и другие ИИ-инструменты для создания и доработки веб-проектов, решения технических задач и работы с цифровым контентом.

## Мои проекты

### Bloom & Balance — информационный сайт

Проект сайта с адаптивным интерфейсом, тематическими разделами и публикациями.

**Моя работа:** AI-assisted разработка, редактирование интерфейса, управление контентом, тестирование, работа с GitHub и Cloudflare.

### Web Gallery — галерея изображений

Веб-проект с галереей, управлением изображениями и отдельными вариантами интерфейса.

**Моя работа:** постановка задач ИИ, настройка функциональности, проверка изменений и исправление ошибок.
